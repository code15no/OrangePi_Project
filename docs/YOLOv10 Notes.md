# YOLOv10 Notes

## Abstract

YOLOv10 是 YOLO 系列的最新迭代，旨在解决传统 YOLO 模型在<u>后处理（NMS）</u>和<u>模型架构</u>方面的不足，实现更高的性能-效率边界。该论文提出了一种**无 NMS 训练策略**和**整体效率-准确率驱动的模型设计策略**，通过<u>一致双标签分配</u>和<u>架构优化</u>，显著提升了实时目标检测的性能。核心公式包括匹配度量和监督差距计算，这些是方法的核心数学基础。

## Introduction

实时目标检测是计算机视觉的核心任务，广泛应用于自动驾驶、机器人导航和目标跟踪等领域。YOLO 系列模型因其在性能和效率间的平衡而备受青睐，但传统 YOLO 依赖 NMS（Non-Maximum Suppression）后处理，导致推理延迟增加和端到端部署受限。同时，模型架构存在计算冗余和能力不足的问题。

论文的贡献包括：

- 提出一致双分配策略，实现无 NMS 的 YOLO 训练，同时保持竞争性能。

- 引入整体效率-准确率驱动模型设计，优化 YOLO 的各个组件，减少冗余并提升能力。

代码[链接](https://github.com/THU-MIG/yolov10)在此处。
