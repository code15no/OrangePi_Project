# 疲劳检测优化（Github）
## 1、DrowsinessDetection
### 源码
Github：https://github.com/xuruif/DrowsinessDetection

CSDN：https://blog.csdn.net/loushangfengjing/article/details/136748855?spm=1001.2014.3001.5501  

### 优势
1、用户可根据硬件条件切换模型（如资源受限场景选 YOLOv5nu/YOLOv7-tiny，精度优先场景选 YOLOv8n），灵活性远超单一模型系统。

2、数据规模与划分合理：总计 16246 张标注图片，按 “8:1:0.7” 划分训练集（13719 张）、验证集（1380 张）、测试集（1147 张），避免过拟合，确保模型在未知数据上的泛化能力。

3、界面体验：低门槛操作，非专业用户友好。
可视化反馈明确：检测结果以 “边界框 + 中文标签 + 置信度” 形式叠加在画面上，表格同步记录每帧数据，用户可快速定位疲劳行为发生时间与强度；
